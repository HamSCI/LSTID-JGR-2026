# Input data

These files are not stored in the repository. The scripts read them from the folder named by the
`LSTID_DATA_DIR` environment variable (default: this `data/` folder).

| File | Used by | Content |
|---|---|---|
| `20140101-20230901_merged.csv` | all figures | Daily LSTID fit results from the HamSCI amateur radio data (this study) |
| `2017_data_full_V2.csv` | Fig 7 | Manual day-by-day LSTID classification for 2017 (this study) |
| `merra2_pvIndex.csv` | Figs 5, 6, 9 | Daily polar vortex index from MERRA-2 reanalysis |
| `sym_ae.lst` | Figs 6, 9 | AE and SYM-H indices, 5-minute, from NASA OMNI |
| `omni2_daily_3hWFoJxMID.lst` | Fig 10 | Daily F10.7 solar radio flux, from NASA OMNI |
| `sza_daily.csv` | Fig 10 | Daily noon solar zenith angle at 39.83N 98.58W |
| `gen_sza.py` | (generates `sza_daily.csv`) | Script that produced `sza_daily.csv` with pysolar |
| `download_giro.py` | (downloads `giro/`) | Script that downloads the GIRO files from DIDBase |
| `giro/giro_<STATION>_<YEAR>.txt` | Fig 11 | GIRO ionosonde characteristics, six stations, 2015-2022 |

## `20140101-20230901_merged.csv`

One row per day, 2014-01-01 to 2023-09-01; the first column is the date. Days without a result are
empty. Produced by the HamSCI LSTID detection code (release `V0.2.0_Sanchez_et_al_2026_MS`, doi:10.5281/zenodo.20186618) applied to 14 MHz
spots over the continental United States from the CEDAR Madrigal HamSCI dataset.

| Column | Meaning |
|---|---|
| `amplitude_km` | Fitted sinusoid amplitude A (km), paper Equation 8 |
| `T_hr` | Fitted period T (hours) |
| `phase_hr` | Fitted phase (hours) |
| `offset_km` | Fitted vertical offset d_0 (km) |
| `slope_kmph` | Fitted linear trend v (km/hr) |
| `r2` | Goodness of fit R^2 of the selected solution |
| `min_combined_fit` | Minimum skip distance d_min (km), paper Equation 10 |
| `fitStart`, `fitEnd` | UTC start and end of the fitted (stable) segment, M/D/YYYY H:MM |
| `duration_hr` | Length of the fitted segment (hours) |
| `T_hr_guess` | Initial period guess that gave the selected fit (hours) |
| `selected`, `agree` | Internal flags from the detection code; not used by these scripts |

## `2017_data_full_V2.csv`

365 rows for 2017. Fig 7 uses `date` and `tid` (hours of LSTID activity identified by manual
inspection; a day with `tid >= 1` is a manual LSTID day). The other columns (`pv`, `ae_slope`, `ae`,
`varea`, `u_nh`, `u_slope`) are from an earlier analysis and are not used.

## `merra2_pvIndex.csv`

No header. Columns: date (M/D/YYYY), polar vortex index (dimensionless). Daily, ending 2022-07-31.
Index defined by Frissell et al. (2016) and computed from MERRA-2 reanalysis by co-author
V. L. Harvey. TODO (author): add computation details and the MERRA-2 citation.

## `sym_ae.lst`

Whitespace-separated, no header: year, day of year, hour, minute, AE (nT), SYM-H (nT). 5-minute
resolution, 2015-2023. Fill value 99999. AE is fill for all of 2020. Scripts use daily means of the
5-minute values.

## `omni2_daily_3hWFoJxMID.lst`

Whitespace-separated, no header: year, day of year, hour, proton density, F10.7 (solar flux units).
Daily values from NASA OMNIWeb. Fig 10 uses F10.7 and treats values <= 0 or > 200 as missing.

## `sza_daily.csv`

Columns: `date`, `sza_noon_deg` (minimum solar zenith angle of the day, degrees) at the geographic
center of the contiguous United States (39.83N, 98.58W), 2014-01-01 to 2023-09-01. Generated by
`gen_sza.py` (requires `pysolar`).

## `giro/`

Tabulated ionospheric characteristics from the Lowell GIRO Data Center (DIDBase), one file per
station per year, for BC840 Boulder CO, AU930 Austin TX, EG931 Eglin FL, AL945 Alpena MI,
WP937 Wallops Island VA, and MHJ45 Millstone Hill MA. Each file has a commented header describing
the columns; scripts use the autoscaled foF2 (column 3) and foEs (column 13) between 13 and 23 UTC.
Missing values are `---`. See `DATA_LICENSES.md` for the license and required acknowledgment.

Download them with `download_giro.py` (writes to `$LSTID_DATA_DIR/giro/`). Run
`python download_giro.py --check` to download into a temporary folder and compare with existing
files.
